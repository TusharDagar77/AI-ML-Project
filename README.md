# AI/ML Medal Prediction Project

## About the Project

This project focuses on predicting the number of medals a country may achieve using historical Olympic data.

The project follows a machine learning workflow that includes data collection, exploratory data analysis, data preprocessing, feature selection, regression modeling, and model evaluation.

## Project Structure

### Phase 1
- Dataset collection and loading
- Understanding the dataset
- Initial data inspection
- Preparing the data for further analysis

### Phase 2
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Handling missing values
- Encoding categorical features
- Feature engineering
- Feature and target selection
- Train-test split

### Phase 3
- Regression model development
- Training machine learning models
- Comparing different models
- Model evaluation
- Performance analysis
- Model optimization

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The project uses historical Olympic data containing information such as:

- Athlete details
- Team/Country
- NOC
- Year
- Season
- Sport
- Event
- Medal

## Machine Learning

The project uses supervised learning and regression techniques to predict medal outcomes.

The evaluation metrics include:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
